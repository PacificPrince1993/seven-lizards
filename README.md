# Seven Lizards

Одностраничный сайт игры «Шалене будівництво». React + Vite, адаптивная верстка, украинский и английский языки. Выбор языка сохраняется на устройстве.

## Запуск

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

Готовые файлы в `dist/` можно разместить на любом статическом хостинге. Маршрутизация сервера не требуется.

## Контент

- `src/content.js`: тексты EN/UA, названия ресурсов и `gameLinks`. Замените `null` реальным URL, и карточка автоматически станет активной ссылкой. Сейчас подключён только предоставленный адрес http://sevenlizards.com/.
- `public/assets/rules-uk.pdf`: финальный PDF с правилами от издателя (8 страниц, ~45 МБ). Доступен и для скачивания, и для чтения онлайн — обе кнопки одинаково заметны. Английский интерфейс явно сообщает, что PDF на украинском.

  Издатель прислал два экспорта одного и того же документа: 82 МБ и 45 МБ. Содержимое идентично (8 страниц, та же геометрия, те же 109 изображений в том же разрешении), но в версии на 82 МБ 55 МБ приходилось на несжатые потоки. Взят меньший экспорт. Размер указан в `fileMeta` в `src/content.js` — при замене файла обновите и его.
- `public/assets/game-clean.webp`: изображение игры из первой страницы правил, с удалённым через ImageGen фрагментом текста над компонентами. ImageGen слегка перерисовывает детали, поэтому перед коммерческой публикацией лучше заменить этот файл оригинальным отдельным изображением игры. Исходный фрагмент сохранён в `public/assets/game.webp`.
- `public/assets/construction-background.webp`: сгенерированная декоративная иллюстрация. Не изображает реальные игровые компоненты.
- `src/styles.css`: оформление и адаптивность.

Название Crazy Construction — рабочий перевод для английского интерфейса; уточните официальное английское название перед запуском. Число игроков 2–5 взято из правил, а не из референса. Возраст и длительность не добавлены без подтверждения.

QR-код для указанного адреса sevenlizards.com находится в `output/qr/`. Он будет вести на существующий адрес; новую страницу необходимо отдельно разместить на этом домене. QR-код не меняет содержимое домена.
